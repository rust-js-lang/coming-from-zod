# Patches to rust-js

The `rust-js` submodule is pinned to a commit of
[rust-js-lang/rust-js](https://github.com/rust-js-lang/rust-js). When a
chapter needs something rust-js doesn't do yet, we patch the submodule,
open an issue upstream, and list both here. When the fix is upstream, the
submodule moves to a commit that has it and the row goes.
